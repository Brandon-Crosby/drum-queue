How to use drum groove MIDI in FL Studio and Ableton

The groove MIDI that comes with every kit is the song's drum pattern, ready to play your one-shots. Here's how it's laid out and how to get it running in a couple of minutes.

How the file is laid out

  • One track per one-shot. The track named "Snare 1" plays Snare 1.wav, and so on. Nothing to remap.
  • Every note is on the same key: MIDI note 60. FL Studio calls that C5, Ableton calls it C3. Same note, different names. A sampler plays a sample at its original pitch on its root note, and in FL Studio the default root note is C5, so every hit plays back exactly as it sounded in the song.
  • Velocity follows the song. Louder hits in the song get higher velocities, so accents and ghost notes survive.
  • Quantized per sound. Each sound is snapped to the grid that fits it: 16th notes for most parts, triplets or 32nd notes only for real rolls. Nothing is forced onto a grid it didn't play on.
  • Bar 1 is the downbeat. The pattern is lined up so the first kick of the groove lands on bar 1.

The zip has two files. Groove.mid is the most typical 8 bars of the song (or 4, if those repeat exactly). Groove (full song).mid is the whole song, for when you want the fills and changes too.

FL Studio

  1. Set the tempo to the song's BPM. The MIDI file carries it, and FL can pick it up on import.
  2. Load the one-shots. Drag each WAV from the browser into the Channel rack. Each becomes a Sampler channel. Name the channels the same as the files to keep things easy.
  3. Import the MIDI. Drag Groove.mid into the Channel rack, or use File → Import → MIDI file. FL creates a channel per MIDI track with its notes. Then, for each one, either move the notes onto the matching Sampler channel, or simply load the matching WAV into that new channel (drag the sample onto it).
  4. Check one channel's root note (in the channel's settings, the keyboard root note). It should be C5. If someone changed it, the hits will play back pitched.
  5. Hit play. You should hear the song's drums, played by your project.

Tip: if you only want the pattern for one sound, open that channel's Piano roll and drag the single-track MIDI notes into it.

Ableton Live

  1. Create a Drum Rack and drop each one-shot onto its own pad, or create one MIDI track per one-shot with Simpler on it.
  2. Drag Groove.mid into the Arrangement. Live asks whether to import tempo and time signature; say yes.
  3. With separate Simpler tracks: each MIDI track lands on its own track. Since every note is C3 (note 60) and Simpler plays the sample unpitched on C3, it just works.
  4. With a Drum Rack: every note arrives on C3, so they'd all trigger one pad. Move each track's notes to its pad's note in the clip editor (select all, then drag), or use one Drum Rack chain per track.

Other DAWs

Any DAW that imports multi-track MIDI works the same way: one sampler per track, sample root note on MIDI note 60, and the notes play the samples at their original pitch. Depending on the DAW, note 60 is labeled C3, C4 or C5. It's the same note in all of them.

Editing the groove

  • Swing. The MIDI is quantized straight. If the song had swing, use your DAW's swing or groove template to put it back (FL Studio: the Channel rack's swing knob; Ableton: groove pool).
  • Humanize. Small random velocity changes on the hats bring back life that quantizing removes.
  • Make it yours. Shift one kick, add a hat roll, change the snare on the last beat of bar 4. The pattern is a starting point, not a finished beat.

When notes seem wrong

If a track has hits where you don't hear that sound, it's usually because two sounds are similar enough that some hits of one were counted as the other (a rim and a snare, two hats).

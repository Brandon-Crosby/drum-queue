# Data credits

Public datasets used (or planned) for training DrumSplitter models. CC BY 4.0 requires attribution.

| Dataset | Authors | License | Use |
|---|---|---|---|
| Groove MIDI Dataset (GMD) | Gillick, Roberts, Engel, Eck, Bamman (Google Magenta), 2019 | CC BY 4.0 | planned: human drum MIDI for synth clips |
| StemGMD | Mezza, Giampiccolo, Bernardini, Sarti (Politecnico di Milano), 2023 | CC BY 4.0 | planned: isolated acoustic drum stems |
| Slakh2100 | Manilow, Wichern, Seetharaman, Le Roux (Northwestern / MERL), 2019 | CC BY 4.0 | planned: stage-1 songs, drum MIDI |
| Expanded Groove MIDI (E-GMD) | Callender, Hawthorne, Engel (Google), 2020 | CC BY 4.0 | planned: drum-bus studies |

Update the "Use" column when a dataset actually goes into a run.
